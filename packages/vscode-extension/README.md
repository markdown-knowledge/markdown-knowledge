# Markdown Knowledge (MDK) for VS Code

Browse, edit and search Markdown Knowledge (`.mdk`) containers directly inside VS Code.

## Features

- **Virtual FileSystem (`mdk:`)**: Edit Markdown documents packed inside `.mdk` files with full VS Code editor support and live preview.
- **Tree View Explorer**: View all `.mdk` containers in the workspace under the "Markdown Knowledge" activity bar view.
- **Interactive Dashboard**: Open any `.mdk` container to view statistics, browse documents, and run instant full-text searches (BM25 ranked via SQLite FTS).
- **Search Command**: Quickly search across container documents and jump directly to matches.
