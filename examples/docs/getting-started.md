# Getting Started

Markdown Knowledge stores many Markdown documents in one `.mdk` file.

## Installation

Install the CLI globally with npm:

```bash
npm install -g @mdk/cli
```

## First container

Create a container and add a document:

```bash
mdk init handbook.mdk --title "Team Handbook"
mdk add handbook.mdk intro --file README.md
```
